# Демонстрационный набор данных

Небольшая обезличенная выборка из OWS v3 для проверки проекта без повторной загрузки API:

- 3 организации;
- 50 планов;
- 100 лотов;
- 50 договоров.

Файлы находятся в `data/sample/export/`. Чтобы запустить Docker на этой выборке:

```bash
mkdir -p data/export
cp data/sample/export/*.jsonl data/export/
docker compose up --build
```

Полная выгрузка не хранится в репозитории. Для неё используйте `exporter.py` с собственным OWS-токеном.
